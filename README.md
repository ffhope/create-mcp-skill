# Create MCP Skill

A skill that guides you through creating standard MCP (Model Context Protocol) server projects for Cursor.

## Installation

```bash
npx skills add ffhope/create-mcp-skill@create-mcp
```

## What This Skill Does

This skill provides step-by-step instructions for:
- Creating standard MCP server project structure
- Developing MCP tools and resources
- Configuring Cursor MCP connections
- Testing and debugging MCP servers
- Understanding MCP architecture and best practices

## Quick Start

1. Read SKILL.md for complete instructions
2. Use the provided scripts to generate a new MCP project
3. Configure Cursor MCP settings
4. Test your MCP server

## Requirements

- Node.js 18 or higher
- Cursor IDE
- GitHub account (for publishing)
- Public repository (for installation via npx skills add)
