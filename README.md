# Create MCP Skill

用于 Cursor 的 Skill，帮助快速创建标准 MCP（Model Context Protocol）服务器项目。

## 安装

将本目录复制到 Cursor skills 目录：

**个人 Skill（推荐）**：
```bash
cp -r create-mcp-skill ~/.cursor/skills/create-mcp
```

**项目 Skill**：
```bash
cp -r create-mcp-skill .cursor/skills/create-mcp
```

## 使用方法

在 Cursor 中直接使用：
- "创建一个名为 xxx 的 MCP 项目"
- "帮我创建标准 MCP 服务器"
- "添加一个新的 MCP 工具"

## 功能

- 创建标准 MCP 项目结构
- 生成基础服务器代码
- 提供工具和资源模板
- 生成 Cursor 配置文件
